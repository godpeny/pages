# 메시지 소재 선택 불안정 — 지연 피드백 관점 분석

> **TL;DR**
> - 문제의 본질은 지연 자체가 아니라 **"몰아주기 → 선두 소재의 샘플이 어려짐 → 저평가 → 선두 교체"** 로 이어지는 피드백 고리다.
> - 현재 학습은 FNW 스트림이다. FNW·ES-DFM·DEFER·DEFUSE 는 길게 보면 맞아지는 방법이라, 다음 발송 전에 맞아야 하는 이 문제를 끝까지 풀지 못한다. **FNW 구조를 유지한 채 이 문제를 푼 논문은 찾지 못했다.**
> - 해법의 부품은 다른 구조에 있다: **① 경과 시간으로 미클릭을 보정 (DFM·TWICE식) ② 보정을 열람 단계에 적용 ③ 1등 몰아주기 대신 확률 비례 배분.**

대상 문서: [(2026-11-12) 클릭 반응 지연에 따른 소재 선택 불안정 현상 개선](https://kakao.atlassian.net/wiki/spaces/adrec/pages/455194404/2026-11-12)

# 1. 우리의 문제

## 현상

- 메시지 최적화 캠페인에서 실시간 학습 SCTR 모델이 리전마다 **최다 발송 소재를 번갈아 바꾼다.**
- 일배치 모델 대비 micro SCTR 개선 폭이 +2.8% 로 기대보다 작았다 (11/3~11/12, 49개 캠페인, 1,740만 건).

## 원인 가설 (대상 문서)

- 발송 후 클릭의 약 50% 가 쌓이는 데 30분이 걸린다. 열람 후 클릭은 약 90% 가 4분 이내다.
- 아직 클릭하지 않은 발송이 미클릭으로 학습된다.
- 최근에 많이 보낸 소재일수록 덜 익은 데이터의 비중이 커서 불리해진다.

## 문제가 생기는 고리

1. 앞서는 소재에 발송을 몰아준다.
2. 그 소재의 샘플은 대부분 방금 보낸 것이라 클릭이 아직 안 왔다.
3. 안 온 클릭이 음성으로 학습되어 그 소재가 저평가된다.
4. 다른 소재가 1등이 되고, 같은 일이 반복된다.

모든 소재가 똑같이 덜 익었다면 순위는 바뀌지 않는다. **몰아주기 때문에 소재마다 샘플 나이가 달라지고**, 그래서 순위가 뒤집힌다. 정책이 편향을 만들고, 그 편향이 다시 정책을 바꾼다.

## 대상 문서의 숫자 예시

소재별 최종 SCTR 은 A 3.2%, B 3.0% 로 가정한다. 1:20 학습 시점에 1:00 발송분은 클릭의 40%, 1:10 발송분은 30% 만 들어와 있다.

| 발송 시각 | 소재 A 발송 | 소재 B 발송 | A 현재/최종 클릭 | B 현재/최종 클릭 |
|---|---|---|---|---|
| 1:00 | 5,000 | 5,000 | 64 / 160 | 60 / 150 |
| 1:10 | 9,000 | 1,000 | 86.4 / 288 | 9 / 30 |
| 합계 | 14,000 | 6,000 | 150.4 / 448 | 69 / 180 |

| 시점 | A SCTR | B SCTR | 높게 보이는 소재 |
|---|---|---|---|
| 1:20 관측 | 1.07% | 1.15% | B |
| 클릭이 다 들어온 뒤 | 3.20% | 3.00% | A |

## 이미 한 조치와 검토 중인 안

- **조치 (11/12)**: 리전 간격 10분 → 25분, 리전 수 10 → 5. 일배치 대비 개선 폭이 +7.1% 로 커졌지만 캠페인 구성이 달라 단정할 수 없고, 반응률이 비슷한 소재에서는 여전히 흔들린다.
- **1안**: 발송-열람, 열람-클릭 헤드를 분리하고 실시간 학습에서는 열람-클릭 헤드만 튜닝한다. 한계는 열람률 헤드를 튜닝하지 못한다는 점이다.
- **2안**: 클릭 라벨 창을 발송 후 N분 (20분 검토) 으로 제한한다. 한계는 그 이후 클릭을 버린다는 점이다.

## 현재 학습 구조 (torch-dnn 확인)

`config/msg/mestra_online_global_v3.0.4.yaml` 기준이다. 이 설정이 실제 운영 버전인지는 확인하지 못했다.

| 항목 | 내용 |
|---|---|
| 손실 | FNW (`loss_info.type: fnw`) |
| 데이터 | Sequoia `msg-sctr-dfom-v1`. 발송 행은 전량 $y=0$, 클릭 행은 $y=1$ 정정으로 한 번 더 들어오는 이중 발행 |
| 학습 방식 | 북마크 이후 구간만 한 번 읽고 지나간다. 지난 행은 다시 보지 않는다 |
| 서빙 | `recalibration: true` 로 $p=b/(1-b)$ 복원 |
| 학습 범위 | 베이스 모델은 고정하고 `message_id` 별 어댑터만 갱신 |
| 발송 시각 | 발송 행에는 `send_dttm` 이 비어 있고 클릭 행에만 있다 |

즉 대상 문서의 현상은 **FNW 가 과도 구간에서 갖는 약점**이 그대로 드러난 것이다. FNW 는 양성 복제가 도착한 뒤에야 편향이 상쇄된다.

# 2. 일반화된 문제 정의

> **지연되어 도착하는 이진 피드백을 보면서, 몇 번 안 되는 라운드마다 여러 선택지에 물량을 적응적으로 배분하는 문제.** 지연이 라운드 간격 및 전체 기간과 같은 크기라서, 결정 시점마다 최근 샘플의 라벨이 잘려 있다.

일반적인 지연 피드백 CVR 문제와 다른 조건은 네 가지다.

| 조건 | 일반 지연 피드백 CVR | 우리 문제 |
|---|---|---|
| 편향이 없어야 하는 시점 | 길게 보아 평균적으로 | 매 결정 시점마다 |
| 샘플 나이와 선택지의 관계 | 무관 | 정책 때문에 상관됨 |
| 선택지의 이력 | 며칠에서 몇 주 | 없음. 매번 새 소재 |
| 필요한 정확도 | 확률값 보정 | 선택지 간 순위 |

이 정의로 보면 관련 연구는 세 갈래다.

- **지연 피드백 밴딧과 적응적 실험** — 문제 구조가 가장 가깝다.
- **스트리밍 지연 피드백 모델링** — FNW 계열이 과도 구간을 다뤘는지 확인할 대상이다.
- **중간 신호와 피드백 고리 안정화** — 먼저 오는 신호의 활용, 배분 진동 완화.

# 3. 선행 연구

원문 페이지에서 제목·학회·연도를 확인한 것만 실었다. 초록만 확인한 논문은 표시했다.

## 3-1. FNW 구조 안에서 해결했는가 — 없음

이중 발행을 유지하는 논문들은 모두 스트림이 충분히 흐른 뒤의 불편성만 증명한다. 샘플의 경과 시간을 가중치 입력으로 쓰지 않고, 새 선택지나 급변하는 물량 배분을 다루지 않는다.

| 논문 | 우리 문제와의 관계 |
|---|---|
| [FNW](https://arxiv.org/abs/1907.06558) (RecSys 2019) | 과도 구간은 분석하지 않았다. 비교한 손실 중 경과 시간을 쓰는 것은 DFM 손실 하나뿐이다 |
| [ES-DFM](https://arxiv.org/abs/2012.03245) (AAAI 2021) | FNW 의 이 약점을 직접 지적한다. 가짜 음성은 양성 복제가 올 때까지 모델을 해친다는 내용이다. 해법은 대기창이다 |
| [DEFER](https://arxiv.org/abs/2104.14121) (KDD 2021) | 진짜 음성 재투입이 어트리뷰션 창 뒤라 100분 안에는 쓸모가 없다 |
| [DEFUSE](https://arxiv.org/abs/2202.06472) (WWW 2022) | 대기창 0 인 FNW 변형이 부록에 있어 그대로 끼울 수 있다. 가중치가 $x$ 만 보므로 나이 불균형은 못 고친다 |
| [DDFM](https://doi.org/10.1145/3583780.3614856) (CIKM 2023) | 신규 데이터와 복제 데이터의 분포가 다르다는 점을 다룬다. 초록만 확인 |
| [FSIW](https://arxiv.org/abs/2002.02068) (WWW 2020) | 경과 시간을 가중치 입력으로 넣은 유일한 중요도 가중 방식이다. 다만 배치 학습이고 복제가 없다 |

## 3-2. 다른 구조를 도입한 해법

### 부품 1 — 나이 보정 추정량

편향을 결정 시점마다 없앤다.

| 논문 | 핵심 | 근거 수준 |
|---|---|---|
| [Vernade 등](https://arxiv.org/abs/1706.09186) (UAI 2017) | 클릭 수를 각 발송의 나이에 해당하는 지연 누적 비율의 합으로 나눈다. 배분 이력이 어떻든 그 시점에서 불편이다. 지연 분포는 선택지 간 공유되고 알려져 있다고 가정한다 | 시뮬레이션 |
| [Wang 등](https://arxiv.org/abs/2202.00846) (WWW 2022, JD.com) | 같은 추정량을 광고 소재 실험에 적용. 지연 분포를 EM 으로 추정하고 톰슨 샘플링에 넣는다 | 실험 플랫폼 배포. 수치 효과 비공개 |
| [TWICE](https://arxiv.org/abs/2607.25404) (2026 프리프린트, Kwai) | 같은 원리의 신경망 버전. 예측 = 최종 전환율 × 관측 나이의 지연 누적 비율 | 전체 트래픽 적용, 전환 +2.06% |
| [Gigli·Stella](https://proceedings.mlr.press/v244/gigli24a.html) (UAI 2024) | 지연 분포를 Kaplan-Meier 로 학습하는 부트스트랩 톰슨 샘플링. 초록만 확인 | 벤치마크 |

TWICE 는 1시간 숙성에 30일 창이라 시간 단위가 우리와 많이 다르다. 식만 빌려 온다.

### 부품 2 — 먼저 오는 신호 활용

| 논문 | 핵심 | 근거 수준 |
|---|---|---|
| [Impatient Bandits](https://arxiv.org/abs/2307.09943) (KDD 2023, Spotify) | 새 선택지에 대해 단계적으로 도착하는 신호로 최종 결과의 사후 분포를 갱신하고 톰슨 샘플링 | A/B. 신규 콘텐츠 지표 50% 이상 개선 |
| [GDFM](https://arxiv.org/abs/2206.00407) (NeurIPS 2022) | 전환보다 먼저 오는 행동을 대리 신호로 학습 | 오프라인 |
| [Vernade 등](https://arxiv.org/abs/2006.02119) (ICML 2020), [Esposito 등](https://arxiv.org/abs/2305.19036) (ICML 2023) | 중간 관측이 있는 지연 밴딧 이론 | 이론 |

주의할 점이 있다. 중간 신호 밴딧 이론은 결과가 중간 신호만 거쳐서 결정된다고 가정한다. 우리는 열람 후 클릭률이 소재마다 다르므로 이 가정이 깨진다. **열람만으로 대체할 수 없고, 열람률과 열람 후 클릭률을 둘 다 추정해야 한다.**

### 부품 3 — 배분 방식

| 논문 | 핵심 | 근거 수준 |
|---|---|---|
| [Chapelle·Li](https://papers.nips.cc/paper/2011/hash/e53a0a2978c28872a4505bdb51db06dc-Abstract.html) (NIPS 2011) | 갱신 지연이 10~60분일 때 결정적 정책은 크게 나빠지고 확률적 정책은 견딘다 | Yahoo 뉴스 실데이터 |
| [Chennu 등](https://arxiv.org/abs/2106.11294) (KDD 2021 워크숍, Apple) | 지연 피드백 아래 배치 톰슨 샘플링의 배분 진동을 문제로 명시. 평활화로 변동을 최대 3.8배 줄임. 편향 제거가 아니라 완화다 | 시뮬레이션 |
| [Desautels 등](https://jmlr.org/papers/v15/desautels14a.html) (JMLR 2014) | 결과가 아직 안 온 선택은 현재 평균값으로 채워, 평균을 움직이지 않게 한다 | 이론 |

지금 방식은 Desautels 와 반대로, 결과가 안 온 발송을 0 으로 채워 평균을 끌어내리는 셈이다.

## 문헌상의 공백

- "몰아주기가 선두의 샘플을 어리게 만들어 선두가 번갈아 바뀐다" 는 고리를 명명하거나 분석한 논문은 찾지 못했다.
- 푸시·이메일의 발송-열람-클릭 깔때기에 지연 보정을 적용한 공개 문헌도 찾지 못했다.

# 4. 방법별 적합도

## 두 계보

| | 지연 분포 계보 | 중요도 가중 계보 |
|---|---|---|
| 방법 | DFM, TWICE, ULC | FNW, ES-DFM, DEFER, DEFUSE |
| 미클릭 처리 | 경과 시간을 보고 "아직 안 온 것" 으로 취급 | 일단 음성으로 넣고, 양성이 오면 다시 넣어 가중치로 상쇄 |
| 편향이 사라지는 시점 | 학습하는 그 순간 | 정정 샘플이 다 도착한 뒤 |

ES-DFM·DEFER·DEFUSE 는 DFM 의 개선판이 아니라 FNW 에서 출발한 다른 계보다.

## 방법별 판정

| 방법 | 소재 간 나이 불균형 | 늦은 클릭 활용 | 판정 |
|---|---|---|---|
| FNW (현재) | 그대로 남음 | 늦게 반영 | 현상의 원인 |
| ES-DFM, DEFUSE | 줄지만 남음 | 늦게 반영 | FNW 보다 낫지만 흔들림이 남는다 |
| DEFER | 그대로 남음 | 캠페인 종료 후 | 효과 없음 |
| 2안 (N분 창) | 없음 | 버림 | 안정적이지만 정보 손실 |
| DFM, TWICE식 | 없음 | 도착 즉시 반영 | 가장 적합 |
| ULC | 없음 | 반영 | 가능하지만 DFM 대비 이점 없음. 보정 라벨에 모델 예측이 들어가 자기 강화 위험 |
| GDFM | — | — | 아이디어만 차용. 열람과 클릭의 관계가 이미 정해져 있어 행동 모델이 과하다 |

## ES-DFM 계열에 흔들림이 남는 이유

대기창 25분으로 적용한다고 하자.

- 발송 행은 25분 뒤에 들어온다. 그때까지 클릭했으면 양성, 아니면 음성이다. 여기까지는 모든 소재가 같은 나이라 공평하다.
- 25분 이후의 클릭은 나중에 양성 행으로 한 번 더 들어온다. 클릭의 절반 이상이 여기에 해당한다.
- 이 늦은 양성은 오래된 발송에서만 먼저 도착한다. 최근에 많이 보낸 소재는 아직 받지 못했다.

같은 편향이 크기만 줄어서 남는다. 가중치 $1+f_{dp}$ 는 스트림이 충분히 흐른 뒤의 평균을 맞추는 장치라, 늦은 양성이 아직 안 온 구간의 불균형은 고치지 못한다.

**2안은 ES-DFM 에서 늦은 양성 재투입을 뺀 것**과 같다. 불균형을 다시 만드는 것이 그 재투입이라, 안정성만 보면 2안이 ES-DFM 보다 낫다. 공수도 ES-DFM 은 파이프라인 변경에 보조 분류기 두 개가 더 필요해 이점이 없다.

이 절은 손실 식에서 유도한 것이고 실험으로 확인한 것은 아니다.

# 5. 제안

## 5-1. 경과 시간 보정

미클릭 샘플을 "클릭 안 함" 이 아니라 "경과 시간 $e$ 까지 아직 클릭 안 함" 으로 다룬다. $F(e)$ 는 클릭할 사람 중 발송 후 $e$ 분 안에 클릭하는 비율이다.

$$
\mathcal{L} = -\,y\log p(x) \;-\; (1-y)\log\bigl(1-p(x)\,F(e)\bigr)
$$

집계 형태로 쓰면 Vernade 추정량이 된다.

$$
\hat{p}_k = \frac{\text{소재 } k \text{ 의 현재 클릭 수}}{\sum_{s} n_{k,s}\,F(e_s)}
$$

대상 문서의 예시에 넣으면 편향이 사라진다.

| | 관측 SCTR | 유효 발송량 | 보정 SCTR | 최종 SCTR |
|---|---|---|---|---|
| 소재 A | 1.07% | 5,000×0.4 + 9,000×0.3 = 4,700 | 150.4 ÷ 4,700 = 3.2% | 3.2% |
| 소재 B | 1.15% | 5,000×0.4 + 1,000×0.3 = 2,300 | 69 ÷ 2,300 = 3.0% | 3.0% |

TWICE식으로 확장하면 창을 여러 개 (예: 5·10·20·40·90분) 두고, 각 샘플이 자기 나이까지의 창을 모두 감독 신호로 쓴다.

$$
\Pr(o\text{ 분 안에 클릭}\mid x) = p(x)\cdot F(o)
$$

- 2안은 창을 20분 하나만 쓰는 특수한 경우다.
- 출력이 최종 클릭률이라 지연이 느린 소재가 손해 보지 않는다.
- $F$ 를 구간별 비율로 두면 지수 분포를 가정하지 않아도 된다. 발송 후 클릭 지연은 열람 대기와 클릭 대기의 합이라 지수 모양이 아니다.
- $F$ 를 발송 시간대 같은 그룹 단위로 공유하면 새 소재도 과거 캠페인의 곡선을 빌려 쓸 수 있다.

## 5-2. torch-dnn 에서 바뀌어야 하는 것

손실만 바꿔서는 안 된다. 가장 큰 변경은 데이터다.

| 영역 | 현재 | 필요한 변경 |
|---|---|---|
| 데이터 | 발송 즉시 $y=0$ 행, 클릭 시 $y=1$ 행 | "발송 후 $o$ 분 시점의 클릭 여부" 행. 경과 시간 컬럼 필요 |
| 손실 | FNW. 입력은 예측값과 라벨 | $p\cdot F(o)$ 와 창 라벨을 비교. 경과 시간도 입력 |
| 모델 | 출력 하나 | 고정된 $F$ 표, 또는 $F$ 헤드 |
| 서빙 | $b/(1-b)$ 복원 | 복원 끄기 |
| 검증 지표 | 이중 발행 전제 | 창 라벨 기준으로 재정의 |

- 발송 행은 나이 0분에 들어오는데 $F(0)=0$ 이라 이 행은 정보를 주지 못한다. Sequoia 파이프라인이 숙성된 행을 내보내거나, 학습기가 지난 구간을 다시 읽어야 한다.
- 지연을 입력으로 받는 DFM 손실과 학습 클래스 (`models/addfmmodel.py`) 는 이미 있다. 지수 분포 가정이라 $F$ 부분은 바꿔야 한다.
- 온라인 학습이 어댑터만 갱신하므로, $F$ 는 과거 캠페인으로 구한 고정 표로 시작하는 편이 쉽다. 모델 구조와 ONNX 내보내기를 건드리지 않는다.

## 5-3. 열람 단계로 보정 옮기기

지연은 거의 발송-열람 구간에 있다.

$$
\text{SCTR} = \Pr(\text{열람}\mid\text{발송}) \times \Pr(\text{클릭}\mid\text{열람})
$$

- 열람한 샘플은 4분 뒤면 클릭 라벨이 사실상 확정이다.
- 미열람 샘플에만 열람 지연 곡선을 적용한다.
- 1안의 한계인 "열람률 헤드를 튜닝하지 못한다" 가 풀린다.

## 5-4. 배분 방식

1등에 몰아주는 대신 예측의 불확실성을 반영해 확률 비례로 배분하면 진동이 줄 수 있다. 현재 배분 로직이 얼마나 결정적인지는 확인하지 않았다.

## 5-5. 검증 순서

1. **모델 없이 집계로 확인** — 오프라인 리플레이에서 소재별 Vernade 추정량을 계산하고, 리전별 소재 순위가 최종 SCTR 순위와 일치하는 비율을 본다. `utils/mestra_polars_replay.py` 에 클릭 지연 컬럼과 순위·리그렛 계산이 이미 있다.
2. **비교군** — FNW (현재), ES-DFM, 2안, 경과 시간 보정.
3. **지연 곡선 점검** — 발송 시간대·소재 유형별로 $F$ 가 얼마나 다른지 확인한다.
4. 효과가 확인되면 신경망 손실과 Sequoia 파이프라인 변경으로 옮긴다.

# 한계와 미확인 사항

- **노이즈는 고치지 못한다.** 5,000건 발송에 SCTR 3% 면 표준오차가 약 0.24%p 다. 3.2% 와 3.0% 의 차이는 라벨이 다 들어와도 구분되지 않는다. 반응률이 비슷한 소재의 흔들림 중 일부는 편향이 아니라 표본 노이즈다.
- **$F$ 가 틀리면 반대로 흔들린다.** $F$ 를 낮게 잡으면 최근 소재가 과대평가된다.
- 5장의 조합안은 문헌의 부품을 엮은 추론이고 발표된 결과가 아니다.
- 대상 문서에 링크된 지연시간 분석 페이지와 이미지는 읽지 않았다.
- 확인한 설정 파일이 운영 버전인지, 실제 배분 로직이 어떤지는 확인하지 않았다.
- 문헌 조사에서 초록만 확인한 논문: DDFM, Gigli·Stella. Chapelle 의 원조 DFM (KDD 2014) 은 인용 논문을 통해서만 확인했다.
