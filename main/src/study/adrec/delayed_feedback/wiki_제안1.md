# 예측기 랜딩 과제 정리

## 1. DFM/DFOM 통합 (next dfm/dfom)

> 목표: 배치 DFM(PURCHASE)과 온라인 DFOM(APP·PF·MEM)이 따로 돌고 있는 것을 **하나의 스트리밍 모델**로 덮는다. 제안 형식은 "현행에 수학적·기술적 문제 A가 있고, 방법 B는 A'로 A를 없애므로 실험할 가치가 있다"로 통일한다.

### 1.1 출발점 — 두 모델은 같은 양을 다른 근사로 추정한다

두 모델이 최소화하려는 것은 같다. 진짜 분포 $p$ 에서의 기대 손실이다.

$$
\mathcal L(\theta) = \mathbb E_{(x,y)\sim p}\big[\ell(x, y; f_\theta(x))\big]
$$

그런데 스트림에서는 라벨이 늦게 와서 $p$ 로 뽑을 수 없다. 두 모델은 각자 다른 우회로를 쓴다.

| | 배치 DFM (`mtldfm_v2`) | 온라인 DFOM (`_fnw`) |
|---|---|---|
| 우회 방법 | 지연 분포를 지수분포로 **가정**해 미전환의 우도를 $1 - p + p\,e^{-\lambda d}$ 로 씀 | 클릭 즉시 0으로 넣고 전환 시 1 복사본을 추가한 뒤 **중요도 가중치** $p/q$ 로 되돌림 |
| 신선도 | 4시간 배치, 20일 창 | 30분 스트림 |
| 편향의 출처 | 지수분포 가정이 틀린 만큼 | 가중치 안의 $p$ 를 모델 자기 출력 $\hat p$ 로 대체한 만큼, 그리고 $q(x) \approx p(x)$ 근사 |

같은 목표를 향해 한쪽은 **분포 가정**으로, 다른 쪽은 **자기참조 가중치**로 간다. 아래 세 문제는 이 두 우회로에서 나온다.

### 1.2 문제 A → 방법 B → A'

**A1. 온라인 가중치가 모델 자기 출력이다.** FNW의 가중치는 양성 $1 + \hat p$, 음성 $(1 - \hat p)(1 + \hat p)$ 이고 $\hat p$ 는 지금 학습 중인 모델의 출력이다. 그래디언트가 0이 되는 지점이 $\hat p = p$ 하나라는 것은 증명돼 있지만, 그 과정은 자기참조다. 모델이 틀린 상태에서는 가중치도 틀리고, 신규 그룹처럼 모델이 아직 틀린 구간에서 특히 불리하다.

- **B1 = ES-DFM.** 대기 창 $e$ 를 두고, 가중치를 **확정 로그로 따로 학습한 분류기** $f_{dp}$(창 뒤 전환 확률), $f_{rn}$(관측 음성이 진짜 음성일 확률)로 만든다. 양성 $1 + f_{dp}$, 음성 $(1 + f_{dp})\,f_{rn}$.
- **A1'.** 가중치가 CVR 모델과 분리되어 자기참조 고리가 끊어지고, 두 인수가 모두 $[0,1]$ 확률이라 값이 유계다. FNW는 $e = 0$ 인 특수해이므로 현행에서 잃는 것이 없다. 대기 창 안에 오는 전환은 처음부터 1로 들어가 가짜 음성의 양 자체도 줄어든다.

**A2. 전환한 클릭만 두 번 들어가 $q(x) \ne p(x)$.** 중요도 가중치의 정확한 식은 $\frac{p(x)}{q(x)} \cdot \frac{p(y \mid x)}{q(v \mid x)}$ 인데, FNW와 ES-DFM은 앞 인수를 1로 **근사**한다. 실제로는 산 사람의 피처가 스트림에 더 자주 등장하므로 그만큼의 편향이 남고, 끝까지 안 산 클릭은 "확실히 0"이라는 정보가 학습에 한 번도 들어오지 않는다.

- **B2 = DEFER.** 어트리뷰션 창이 지나면 **모든 클릭**을 확정 라벨로 한 번 더 넣는다.
- **A2'.** 모든 클릭이 정확히 두 줄이 되어 $q(x) = p(x)$ 가 근사가 아니라 **등식**이 된다. 앞 인수가 사실로 1이 되고, 진짜 음성 정보가 처음으로 모델에 들어온다. 대가는 데이터 2배와 어트리뷰션 창만큼의 지연이다. 1일 창(vcvr)에서 이득이 크고 7일 창에서는 확인이 필요하다(DEFUSE 논문 표: Criteo-1d에서 ES-DFM보다 우세, 30d에서 열세).

**A3. 배치 DFM은 지연을 지수분포로 가정한다.** 미전환 항 $\log(1 - p + p\,e^{-\lambda d})$ 를 $p$ 로 미분하면 크기가 $F(d) = 1 - e^{-\lambda d}$ 에 비례한다. 가정이 맞아도 최근 클릭의 기울기는 거의 0이고($\lambda = 0.7/\text{일}$ 이면 2시간 전 클릭은 5.6%), 신규 그룹은 데이터가 전부 최근이라 자기 데이터로 스스로를 교정하지 못한다. 가정이 틀리면 그 위에 편향이 얹힌다. 게다가 이 손실은 스트림에서 수렴하지 못한다(ES-DFM 논문: Criteo NLL 1.26으로 발산).

- **B3 = DEFUSE (ES-DFM·DEFER 위에).** 관측 음성 하나를 "가짜 음성일 확률 $z$"와 "진짜 음성일 확률 $1 - z$"로 쪼개 양성 항과 음성 항에 동시에 넣는다. $z = 1 - f_{rn}$ 으로 별도 분류기에서 나온다.
- **A3'.** 지연 분포에 대한 **파라메트릭 가정이 없다.** "창 뒤 전환인가"를 분류기가 직접 맞히므로 $p(h > e)$ 를 따로 모델링하지 않는다. 미전환 샘플이 침묵하지 않고 $z$ 만큼 양성 방향 기울기를 즉시 낸다. 이상적 $z$ 아래 손실이 진짜 라벨 손실과 기댓값이 같다(점근 불편).

### 1.3 통합의 논리

세 방법은 같은 대기 창 스트림 위에 쌓인다. ES-DFM이 창과 보조 헤드를 깔고, DEFER가 재투입 대상을 넓히고, DEFUSE가 음성 항을 쪼갠다. 이 셋을 얹은 스트리밍 모델은 배치 DFM이 하던 일(지연 보정과 불편 추정)을 **지연 분포 가정 없이, 30분 신선도로** 한다. 그래서 PURCHASE를 배치에서 스트림으로 옮길 근거가 생기고, 네 라인이 한 모델이 된다.

근거가 있는 부분과 확인해야 하는 부분을 갈라 둔다.

| | 근거 |
|---|---|
| 배치 DFM 손실은 스트림에서 무너진다 | ES-DFM 논문 표 (DFM Criteo NLL 1.26, Vanilla 0.40) |
| 스트림 방법이 NLL 간격을 메운다 | ES-DFM R-NLL 0.68 (Criteo), DEFER RI-NLL 96.6%, DEFUSE RI-AUC 52.3% |
| Alibaba가 2026년에도 ES-DFM 가중치를 골격으로 쓴다 | TESLA (WWW 2026) 식 (1)·(2), 부록 C |
| **7일 창에서 스트림 방법이 배치 DFM만큼 되는가** | 논문 없음. 우리 데이터로 확인 |

### 1.4 통합 시 맞춰야 할 구조 차이

`torch-dnn_dfm_dfom.md`에 정리된 차이다. 통합 모델이 전부 흡수해야 한다.

| 항목 | 배치 DFM | 온라인 DFOM | 통합 시 |
|---|---|---|---|
| 헤드 | action_type별 $K$개 + $\lambda$ 헤드, `output_mask`로 합산 | 단일 (MEM은 MTL) | action_type별 헤드 유지, $\lambda$ 헤드 → $f_{dp}$·$f_{rn}$ 헤드로 교체 |
| 후처리 | `conv_multiplier` (mpc) | 없음 | 유지 여부 결정 |
| 어트리뷰션 창 | 7일 | 7일 (vcvr 1일) | DEFER 재투입 시점 = 창 |
| 데이터 | parquet 20일 | Sequoia 스트림 | 스트림 + 재투입 경로 |
| 복수 전환 | 미지원 | 미지원 (넥슨 사례, CVR 350%) | 별도 판단 |

### 1.5 실험 설계

셋이 같은 스트림을 쓰므로 **오프라인 스트리밍 재생으로 한 번에 비교**하고 승자만 온라인 A/B로 올린다.

| 팔 | 내용 |
|---|---|
| 대조군 | 현행 `_fnw` ($e = 0$) |
| A | ES-DFM |
| B | + DEFER 재투입 |
| C | + DEFUSE $z$ |
| D | B + C |
| 참조 | 배치 DFM (PURCHASE 라인에서만) |

지표는 성숙 구간 RIG·캘리브레이션(제약)과 신규 그룹 $N$ 곡선(목적)이다. 온라인은 팔을 둘 이하로 줄인다. 신규 그룹이 목표 지표라 팔이 늘면 표본이 부족하다.
